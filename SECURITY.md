# Security policy

## Supported versions

Security fixes are provided for the latest 2.x release.

## Reporting a vulnerability

Please do not publish an unpatched vulnerability in a public issue. Use the
repository's **Security → Report a vulnerability** option to open a private
GitHub security advisory. Include:

- The affected command or file
- Kali/Xfce version and desktop environment
- Reproduction steps
- Expected and actual behavior
- Potential impact
- A suggested fix, if available

Do not include real passwords, API keys, tokens, or personal data. A report will
be acknowledged as soon as practical and coordinated before public disclosure.

## Scope

Issues involving path validation, unsafe configuration restoration, privilege
boundaries, remote-theme imports, shell injection, or unexpected system changes
are considered security relevant.
